# Conor Brown — Engineering Portfolio

Personal portfolio, project catalog, and engineering writing built with Astro, Tailwind CSS and MDX.

## Local development

Requires Node.js 22.12+.

```bash
npm ci
npm run dev
npm run build
```

The blog content lives under `src/blog/*.mdx` with dynamic posts in `src/pages/posts`. Main sections live in `src/pages`.

## Before launch

- Add a verified LinkedIn URL and an approved, current résumé PDF.
- Review each employment case study for employer confidentiality and factual precision.
- Replace placeholder project descriptions with screenshots, detailed walkthroughs, and verified links.
- Configure production site URL / sitemap / canonical tags after domain selection.
- Verify mobile navigation, accessibility and production build.
- Connect Railway deployment and the chosen custom domain.
